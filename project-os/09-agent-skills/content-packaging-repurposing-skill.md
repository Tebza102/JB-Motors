# Content Packaging Repurposing Skill

## Purpose
Turn one source into many sales and marketing assets without losing message integrity.

## Supported Repurposing Targets
- website copy
- service page copy
- social media posts
- WhatsApp campaign copy
- email campaign copy
- proposal sections
- flyer copy
- FAQ section
- sales script
- video script
- landing page copy
- lead magnet outline

## Required Inputs
- content source
- target audience
- platform
- tone
- CTA
- format constraints
- risk check

## Repurposing Matrix (Mandatory)
For each output include:
1. source segment
2. target channel
3. adaptation style
4. CTA
5. approval risk notes

## Required Output
1. repurposing matrix
2. channel-ready drafts
3. consistency and compliance notes
