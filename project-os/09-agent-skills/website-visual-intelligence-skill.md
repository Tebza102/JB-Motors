# Website Visual Intelligence Skill

## Purpose
Extract website visual language deeply so brand assets inherit real design identity, not just colors/logos/text.

## Required Extraction
- background motifs
- grid systems
- abstract shapes
- dashboard cards
- glass-style panels
- growth lines
- data nodes
- icon language
- illustration style
- CTA style
- image treatment
- typography scale
- section rhythm
- brand atmosphere
- distinctive visual motifs

## Visual Motif Inventory (Mandatory)
For each motif record:
1. motif name
2. where it appears
3. how to adapt it to asset types
4. where it should not be used
5. risks: clutter, readability, export clipping

## Graphic Distribution Plan (Mandatory)
Define visual distribution for:
- cover page
- company overview
- problem section
- solutions section
- why-us section
- process section
- engagement/pricing section
- final CTA section

## Graphic Density Rules
- business profiles: moderate visual energy
- proposals: credibility + readability balance
- invoices/quotes: subtle branding only
- slide decks: stronger visual language allowed
- procurement docs: professional and legible first

## Required Output
1. visual motif inventory
2. graphic distribution plan
3. density rules by asset
4. reuse/avoid list
5. export-readiness risks
