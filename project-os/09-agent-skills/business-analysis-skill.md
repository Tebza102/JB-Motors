# Business Analysis Skill

## Purpose
Use this skill to convert an idea into a clear business and product direction.

## Process
1. Define the problem.
2. Define users and buyers.
3. Define measurable value.
4. Identify revenue or cost-saving logic.
5. Challenge assumptions.
6. Recommend lean MVP scope.

## Output Required
- Business problem
- User segments
- Value proposition
- Commercial logic
- Risks
- MVP recommendation
