# Document Intelligence Simplification Skill

## Purpose
Convert complex documents into clear, practical, reusable outputs.

## Supported Inputs
- business profiles
- proposals
- technical documents
- reports
- policies
- compliance documents
- design documents
- invoices/quotations
- client briefs
- discovery forms

## Required Outputs
- plain-language summary
- executive summary
- key facts
- risks
- action points
- reusable marketing snippets
- simple technical glossary
- missing information list
- content packaging suggestions

## Process
1. classify document type
2. extract key claims/facts/constraints
3. simplify language by audience
4. mark gaps and assumptions
5. produce reusable content blocks
