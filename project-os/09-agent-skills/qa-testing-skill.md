# QA Testing Skill

## Purpose
Use this skill to test a feature, bug fix, deployment, or MVP.

## Required Reading
- `/project-os/06-quality/test-plan.md`
- `/project-os/06-quality/smoke-test-checklist.md`
- `/project-os/02-product/product-requirements.md`

## Process
1. Identify the feature or workflow to test.
2. Define expected behavior.
3. Run happy-path test.
4. Run failure-path test.
5. Test mobile if relevant.
6. Record findings.

## Output Required
- Test cases
- Pass/fail results
- Bugs found
- Severity
- Recommended next action

## Extended QA For Branded Assets And Exports
- Run `visual-export-qa-skill.md` for visual export QA.
- Inspect print preview and all PDF pages for layout defects.
- Validate brand consistency and graphic consistency across asset set.
- Run controlled-fix regression checks using `controlled-fix-guardrail-skill.md` after targeted fixes.
