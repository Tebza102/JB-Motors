# Brand Asset Generation Skill

## Purpose
Generate a complete, consistent branded asset system from a website or brand source.

## Supported Assets
- business profile
- company profile
- proposal
- invoice
- quotation
- pitch deck
- presentation slide deck
- email signature
- letterhead
- social assets
- flyer
- case study
- capability statement

## Required Rules
- Extract brand tokens: colors, typography, logo usage, spacing, radius, borders, shadows, buttons, icon style, visual mood.
- Separate website content from document-ready content.
- Reuse brand language, but adapt layout per asset type.
- Do not make every asset look like a website screenshot.
- Do not make every asset look like a plain Word document.
- Every asset must include a QA checklist.

## Asset-Specific Constraints
- Profiles/proposals: stronger narrative + controlled graphic rhythm.
- Invoices/quotations: clean, subtle branding, high readability.
- Slide decks: stronger visual language allowed with structure discipline.
- Email signatures: compact, legible, not image-heavy.

## Required Output
1. brand token map
2. asset list and priority
3. per-asset layout strategy
4. QA checklist per asset
5. risks and missing info
