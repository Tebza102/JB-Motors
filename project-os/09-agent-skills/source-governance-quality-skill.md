# Source Governance Quality Skill

## Purpose
Protect quality, legal safety, and credibility across content and branded assets.

## Mandatory Checks
- whether claims need sources
- whether facts are current
- whether copied text is too close to source
- whether sensitive/private information is exposed
- whether client data is used safely
- whether content matches brand
- whether claims are realistic
- whether content is safe to publish

## Required Governance Artifacts
- source log
- confidence level
- publish readiness status
- approval checklist

## Risk Labels
- High: legal/privacy/false-claim risk
- Medium: weak sourcing/outdated claims
- Low: minor wording/structure adjustments

## Required Output
1. governance checklist result
2. confidence summary
3. publish readiness decision
4. remediation actions if blocked
